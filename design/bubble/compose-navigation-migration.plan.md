# Полный переход Android-приложения на Compose

Исходная точка — `design/fix-design`, коммит `9bb62652`. Все 18 экранов основного графа, вход по PIN и восстановление PIN уже отрисовываются в Compose. Лист переименования удалён. Редактирование имени и фото доступно в карточке человека. В рабочем UI XML ещё загружает контейнер навигации и рекламный баннер через `activity_main.xml` и `view_ad_banner.xml`. Часть устаревших разметок ещё упоминается в адаптерах и ссылках для предпросмотра. [Основное окно](../../app/src/main/java/com/breckneck/debtbook/core/MainActivity.kt). Исходный XML-граф находится в `app/src/main/res/navigation/nav_graph.xml` на коммите `9bb62652`.

Цель — Compose-оболочка и Compose-навигация для существующих сценариев. Будущему переносу на Kotlin Multiplatform помогут переносимые маршруты и явные границы с Android SDK. В объём этого этапа входят UI и навигация Android. Схема БД, формат резервных копий, правила расчёта денег, модель монетизации и подключение iOS за пределами этапа.
