# P0 / R1a — проверка 14–15 ноября 2026

## Срез и изменения

База: `9be2dbe` (`develop_main`), рабочая ветка `codex/p0-r1a-reliability`. Начальное дерево было чистым. Четыре исправления из аудита уже входили в базу; повторный cherry-pick не выполнялся. `roadmap/phase2.2.3` не объединялась.

- P0: восстановлена компиляция domain-тестов, CI покрывает рабочие ветки/все PR и выполняет сборку, unit tests и lint. Убран debug signing у release; существующий ключ задается защищенной конфигурацией. Карта проекта и фичевые документы обновлены.
- R1a: target API 36; исправлены передача Double, полный разбор десятичного ввода с точкой/запятой, смена знака и повторное сохранение. Запись долгов/баланса и удаления объединены в Room-транзакции; навигация следует после успешной записи.
- PIN: удален обход долгим нажатием, MainActivity не экспортируется, доступ требует проверенной сессии; потерянный/поврежденный PIN не отключает защиту. Убрана возможность подменить действие через внешний Intent.
- История: SavedStateHandle хранит ID/фильтр/сортировку, ошибки дают повтор вместо бесконечного индикатора. Backup читает свежий snapshot при каждом upload и валидирует JSON до транзакционной замены.
- UI: отступы API 35/36 и IME, прокрутка к активному XML-полю, видимые кнопки сохранения, контраст FAB в темной теме, удален глобальный предел fontScale 1.2. Устранен непрерывный redraw CustomSwitchView.
- Interstitial разрешен только при явном переключении основных вкладок: пауза 180 секунд, максимум две попытки за процесс, запрет параллельных показов. Из ввода, сохранения и истории показы убраны.

## Воспроизведение локальных проверок

JDK 17, Gradle wrapper 9.4.1, Android SDK/Build Tools 36.0.0:

```sh
JAVA_HOME="$(/usr/libexec/java_home -v 17)" bash ./gradlew \
  :app:assembleDebug :app:assembleDebugAndroidTest \
  :domain:test :data:test :app:testDebugUnitTest :app:lintDebug \
  --continue --console=plain
```

Все Android-тесты запускались на отдельных временных AVD, созданных в `/tmp/simpledebt-r1a/avd`. Пользовательские устройства и базы не использовались. Тесты меняют данные/PIN тестовой установки: их следует запускать только на отдельной установке.

```sh
adb -s emulator-5554 install -r 'app/build/outputs/apk/debug/SimpleDebtBook-v4.6.4(42).apk'
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell am instrument -w -r \
  com.breckneck.debtbook.test/androidx.test.runner.AndroidJUnitRunner
```

Для темной темы передать `-e r1aTheme dark`, для выборочного набора — `-e class com.breckneck.debtbook.debt.DebtReliabilityTest`. Крупный шрифт задавался системной настройкой `font_scale=1.5`, locale на API36 — `cmd locale set-app-locales`. После проверки настройки временного эмулятора восстановлены.

## Неуспешные промежуточные проверки

Исходные domain-тесты не компилировались без coroutines-test; зависимость добавлена. Первый Android-прогон был остановлен из-за бесконечного redraw переключателя; цикл исправлен. Первый lint нашел 13 ошибок, они устранены.

Поздний повтор API36 сорвался из-за системного диалога «System UI isn't responding»; запуск до полного завершения перезагрузки также не засчитан. После перезапуска отдельного AVD проверки повторены. Первая попытка process death через убийство instrumentation завершила и тестовую задачу; она не доказывает восстановление обычного приложения и не включена в успешные результаты.

Уточнение IME-теста выявило скрытое поле суммы при fontScale 1.5, а затем скрытую кнопку сохранения при свернутом AppBar. Исправления сопровождаются проверками фактической видимости и положения поля/кнопки после завершения анимации клавиатуры. Ранние снимки до окончания анимации не считаются визуальной проверкой клавиатуры.
