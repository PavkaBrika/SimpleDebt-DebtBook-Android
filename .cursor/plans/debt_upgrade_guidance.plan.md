# Подсказки по долгам после обновления

Реализовать на актуальном `develop_main`. После обновления пользователь должен понять, как найти долги в других валютах и где находится история из прежних версий. Область работы — экраны долгов, навигация к существующим разделам и локальные отметки ознакомления.

[Объединённый прототип](/Users/pavel/.codex/visualizations/2026/11/25/01a21133-3f13-7050-8cda-a828769a4f68/debt-upgrade-guide.html) показывает расположение и стиль. Для кнопки в карточке человека действуют две ветки из таблицы ниже.

## Правила показа

**Попап.** Открыть один раз при первом входе обновившегося пользователя в «Долги», после успешной загрузки данных. Если приложение восстановило «Финансы», «Цели» или «Настройки», дождаться входа в «Долги». Заголовок «Долги после обновления», текст «Ваши записи на месте. Вот где их найти.», кнопка «Понятно». Включить только подходящие темы.

| Тема | Условие | Текст в попапе |
| --- | --- | --- |
| Долги по валютам | Есть записи в валюте, отличной от текущей валюты списка. Учитывать весь список долгов до фильтра и поиска. | Смените валюту в карточке баланса, чтобы увидеть другие долги. |
| Ранние записи | Хотя бы у одного человека есть записи в `PersonDebtHistory.earlyEntries`. | История из прежней версии доступна в карточке человека. |

Если ни одна тема не подходит, открыть обычный список. Закрытие попапа отмечает только сам попап. Обе подсказки сохраняют своё состояние между запусками и исчезают по отдельности после соответствующего действия или закрытия крестиком.

**Подсказка о валюте.** Разместить под карточкой баланса. Заголовок «Долги в других валютах», текст «Смените валюту, чтобы увидеть остальные долги». Кнопка **«Открыть список валют»** открывает тот же выбор, что и нажатие на код валюты в карточке. Отметить ознакомление после явного выбора другой валюты с записями. При отмене, повторном выборе текущей валюты и автопереключении после добавления долга сохранить состояние ознакомления.

**Подсказка о ранних записях.** Разместить над вкладками карточки человека, только если у него есть ранние записи. Заголовок «Записи из прежней версии».

| Какая вкладка открыта | Кнопка | Результат |
| --- | --- | --- |
| «Открытые долги» или восстановленная вкладка «Погашенные долги» | **Открыть ранние записи** | Выбрать «Ранние записи» и показать историю. Подсказка исчезает. |
| «Ранние записи» открылись автоматически или восстановились как активная вкладка | **Понятно** | Закрыть подсказку и оставить пользователя в истории. |

Если пользователь сам переходит на «Ранние записи» нажатием на вкладку из другого раздела, это также завершает подсказку. Автоматический выбор при загрузке сохраняет подсказку с кнопкой «Понятно». После ознакомления достаточно одной отметки на установку для всех карточек.

## Таск-лист реализации

### 1. Определить применимость и состояние

- [x] Проверить актуальную ветку и состояние дерева. Сверить точки входа с файлами проекта перед правками.
- [x] Определять обновлённую установку по принятому в проекте сигналу. В [App.kt](../../app/src/main/java/com/breckneck/debtbook/app/App.kt) уже используется сравнение `PackageInfo.firstInstallTime` и `lastUpdateTime`. Проверка для подсказок должна работать и в debug-сборке.
- [x] При первом успешном открытии «Долгов» зафиксировать применимые темы этого обновления. Для решения использовать фактическую валюту списка и загруженные записи. `overviewCurrencies` включает валюту по умолчанию даже без записей, поэтому сам список доступных кодов для проверки недостаточен.
- [x] Получать наличие ранних записей из существующего `PersonDebtHistory`. Для попапа проверить историю всех людей, для подсказки — историю открытой карточки. Если подходящие записи удалены, скрыть соответствующую подсказку.
- [x] Хранить в постоянных локальных настройках применимость и три независимые отметки: закрытие попапа, завершение подсказки о валюте и завершение подсказки о ранних записях. Новые записи после первого входа не должны вызывать запоздалый попап об этом обновлении.

### 2. Подключить попап и подсказку на списке долгов

- [x] Встроить попап и подсказку в обычный вход через [DebtFragment](../../app/src/main/java/com/breckneck/debtbook/debt/main/DebtFragment.kt) и [DebtListScreen](../../app/src/main/java/com/breckneck/debtbook/debt/main/DebtListScreen.kt). Показ попапа привязать к видимому экрану и успешной загрузке данных после входа или разблокировки.
- [x] Для кнопки из подсказки переиспользовать маршрут выбора валюты из карточки баланса. Обрабатывать результат явного выбора отдельно от `mainFragmentKey`, который может менять валюту после добавления долга. [DebtViewModel](../../app/src/main/java/com/breckneck/debtbook/debt/main/DebtViewModel.kt) уже хранит текущую валюту и полные данные людей.
- [x] Использовать текущий стиль Bubble. Добавить локализуемые ресурсы для заголовков, сообщений, кнопок и доступных названий крестиков. В списке достаточно кода валюты в карточке и временной подсказки.

### 3. Подключить подсказку в карточке человека

- [x] В [DebtDetailsScreen](../../app/src/main/java/com/breckneck/debtbook/debt/details/DebtDetailsScreen.kt) показывать подсказку над вкладками после получения истории. Выбирать текст кнопки на основе активной вкладки.
- [x] Переходить в «Ранние записи» через существующий механизм выбора вкладки в [DebtDetailsViewModel](../../app/src/main/java/com/breckneck/debtbook/debt/details/DebtDetailsViewModel.kt). Различать обычный переход по нажатию и программный выбор при загрузке или восстановлении состояния.
- [x] Убедиться, что при открытии карточки без открытых долгов и с ранними записями по-прежнему сразу видна ранняя история, в том числе когда есть погашенные долги.

## Таск-лист приёмки

- [x] На обновлённой установке проверить четыре набора данных: обе темы, только другая валюта, только ранние записи, ни одной темы. Проверить также свежую установку. В отдельном примере оставить записи только в EUR при выбранной USD — подсказка о валюте должна помочь найти эти записи.
- [x] На двух карточках проверить обе ветки истории. Смешанная история открывает «Открытые долги», переход по кнопке показывает старые записи. Карточка без открытых долгов открывает «Ранние записи» с кнопкой «Понятно». При просмотре человека без ранних записей подсказка скрыта.
- [x] Проверить ручной переход по вкладке, закрытие каждой подсказки, отмену выбора валюты, повторный выбор той же валюты и действительную смену валюты. После перезапуска и восстановления экрана сверить независимые отметки и состояние выбора вкладки.
- [x] Через обычную точку входа проверить вход после восстановления последней вкладки и первый вход в «Долги». Закрыть попап и пройти к долгу в другой валюте и к ранней истории без пояснений извне.
- [x] Покрыть правила показа и завершения подсказок целевыми тестами. Для проверки интерфейса использовать сценарии из [BubbleDebtJourneyTest](../../app/src/androidTest/java/com/breckneck/debtbook/debt/BubbleDebtJourneyTest.kt), где уже проверяется автоматический выбор ранней истории.
- [x] На выделенном тестовом AVD обновить приложение поверх 4.6.3 или 4.6.4 с тестовыми данными и сверить балансы, даты, комментарии и принадлежность записей. Можно использовать исходный набор ручной проверки, где у Alex две операции на +120,50 и −20,25 USD, а у Maria долг −75,40 EUR. Для смешанной карточки добавить Alex открытый долг через интерфейс новой версии.
- [x] Ориентироваться на минимальный поддерживаемый Android и актуальный стабильный из установленных образов согласно инструкциям владельца. После проверки, включая неудачную, остановить и удалить созданный для неё временный AVD и его файлы.
- [x] Отметить выполненные пункты и записать фактические сборки, команды, устройства, результаты и оставшиеся проверки в этом плане.
